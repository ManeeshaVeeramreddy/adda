# Portfolio Logging – ELK Stack

## Overview

The ELK Stack is used to collect, store, and visualize logs generated by the portfolio application.

The logging implementation uses Filebeat, Elasticsearch, and Kibana to help observe application activity and investigate issues.

## Technologies Used

- **Filebeat:** Collects and forwards log data.
- **Elasticsearch:** Stores and indexes log data.
- **Kibana:** Provides a graphical interface to search and visualize logs.

## Architecture

Portfolio Docker Container → Filebeat → Elasticsearch → Kibana

## Implementation

1. Portfolio application runs inside a Docker container.
2. Filebeat collects the portfolio container logs.
3. Filebeat forwards the collected logs to Elasticsearch.
4. Elasticsearch stores and indexes the log records.
5. Kibana connects to Elasticsearch to search and visualize the logs.

## Configuration and Verification

- Elasticsearch runs on the Ubuntu environment.
- Kibana provides access to the indexed log records.
- Filebeat forwards portfolio logs directly to Elasticsearch.
- The Kibana data view is named `Portfolio Logs`.
- The portfolio log index uses the pattern `portfolio-logs-*`.

## Benefits

- Centralized application log collection.
- Easier searching and analysis of application logs.
- Helps identify errors and troubleshoot issues.
- Provides visibility into application activity.

## Conclusion

The ELK Stack logging setup provides a centralized way to collect, store, search, and visualize portfolio application logs.
